# 辅导员工作站 · 本地版（WorkStation · MVC + SQLite）

完全运行在本机、不联网、不共享的单机版辅导员工作平台。所有业务数据保存在本地 **SQLite 数据库**（`db/workstation.db`）中，通过浏览器使用；上传的重点关注材料与奖助材料文件分别保存在本地「重点关注文件」「奖助文件」文件夹。

### 奖助管理模块使用说明

奖助管理包含「困难认定」「奖学金」「助学金」三个栏目，**仅用于数据的汇总显示，不含审批流程**：

- **批量导入**：点击「批量导入奖学金 / 助学金」→ 选择 CSV 文件或从 Excel 粘贴（表头：学号、名称、等次、获评学年、获评时间，五项必填）→ 解析预览 → 确认导入；学号自动绑定学生台账，未匹配、等次无效、重复的行会跳过并列出明细；也可下载导入模板；
- **批量导出**：点击「批量导出」→ 勾选需要导出的**学生台账列**（学号 / 姓名 / 性别 / 籍贯 / 班级 / 宿舍 / 民族 / 政治面貌 / 通讯地址 / QQ / 电话 / 备注）与**奖助学金列**（类型 / 名称 / 等次 / 获评学年 / 获评时间）→ 导出 CSV（已链接学生台账，默认勾选常用列）。

## 快速开始

1. **双击「启动工作站.command」**（首次双击若提示“无法打开，因为无法验证开发者”，请右键 → 打开 → 打开）。
2. 终端会显示服务已启动，并**自动打开浏览器**进入工作台。
3. 停止使用：关闭弹出的终端窗口，或在该窗口按 `Ctrl+C`。数据始终保留在数据库中。

> 依赖：仅需 macOS 系统自带的 Python 3（`/usr/bin/python3`，标准库自带 sqlite3），**无需安装任何软件**。若系统缺少 python3，脚本会提示。

## 数据存储

- **全部业务数据入数据库**：学生台账、谈心谈话、重点关注、奖助管理（项目/认定/申报）、文件索引、画像标签、设置、元信息均存于 `db/workstation.db`（SQLite）。
- 每次新增 / 修改 / 删除 / 上传后**自动写入数据库**，无需手动保存或导出。
- 学号在台账中**唯一**：手动保存与批量导入都会校验，重复则拒绝（批量导入跳过重复行并列出失败明细）。
- 同项目同学生的奖助申报记录**唯一**：重复添加会被数据库唯一约束拒绝。
- 上传文件实体写入本地文件夹（`重点关注文件/` 与 `奖助文件/`），自动改名为 `YYYYMMDD-姓名-文件类型.扩展名`（同名自动加序号），仅存本机。

## 奖助管理板块使用说明

奖助管理包含「困难认定」「奖学金」「助学金」三个栏目，**仅用于数据的汇总显示，不含审批流程**：

1. **困难认定**：可逐条新增（输入姓名/学号选择学生，每生每学年一条，重复自动更新），或「批量导入名单」下载模板按 学号、等级、评议结果、学年 导入；等级限 特别困难 / 困难 / 一般困难。
   - 认定结果自动并入该生画像成长时间轴；编辑表单会提示是否需同步调整经济关注级别。
2. **奖学金 / 助学金**：汇总展示获评情况（总条数、覆盖学生数、一等/二等/三等/不记等次分布），可按姓名/学号、等次、获评学年筛选。
   - **批量导入**：选择 CSV 文件或从 Excel 粘贴，表头 学号、名称、等次、获评学年、获评时间 五项必填；学号自动绑定学生台账（未匹配跳过并列出明细）；等次限 一等/二等/三等/不记等次；同一学生同一名称同学年重复跳过；支持下载导入模板。
   - **批量导出**：勾选学生台账列与奖助学金列后导出 CSV（已链接学生台账，默认勾选常用列）。

## 重点关注板块使用说明

1. **标记关注**：进入「重点关注」板块，选择学生 → 在 心理（红/橙/黄/严重/一般）、学业 / 思政 / 经济（红/橙/黄）四类上选择级别或「无」→ 保存。标记会同步显示在学生台账列与学生画像中；也可用「批量导入重点关注」按 学号、类型、级别 三列批量导入（学号须与台账一致）。
2. **上传材料**：选择学生 → 选择文件类型（证明材料 / 谈话记录 / 家访记录 / 一生一策 / 其他，可选自定义类型）与日期 → 选择文件上传。
   - 文件自动改名为 `YYYYMMDD-姓名-文件类型.扩展名`（如 `20261022-张雨桐-谈话记录.docx`），同名时自动加序号（`-2`）。
   - 文件实体保存在项目 `重点关注文件/` 文件夹，仅存本机；「打开重点关注文件文件夹」按钮可在访达中打开。
   - 上传后自动登记到该学生的画像成长时间轴与关联材料中。
3. **删除材料**：在已归档材料中点击「删除索引」仅删除索引记录，实体文件保留（避免误删）。

## 导出与批量导入

- **配置化导出**：学生台账与谈心谈话的「导出」按钮弹出配置窗口——勾选要导出的列（可全选/清空）、选择范围（全部记录 / 当前筛选结果），导出的 CSV 为 UTF-8 带 BOM（Excel 打开不乱码），文件名自动包含日期与范围（如 `学生台账_2026-10-23_筛选结果.csv`）。
- **谈话批量导入**：「谈心谈话 → 批量导入 → 下载导入模板」，模板列为 谈话时间、地点、姓名、学号、性别、年级、学历、话题、谈话要点记录、备注；必填 谈话时间 / 学号 / 谈话要点记录，按学号匹配台账学生，未匹配或缺失必填项的行跳过并在预览中列出明细。

## 从旧版（单文件 HTML）迁移数据

旧版数据在两个位置：浏览器本地存储（localStorage）或“数据文件夹”中的 JSON / CSV 文件。迁移方式：

- **学生台账**：旧版设置页或文件中心可导出 `学生台账_日期.csv` → 新版本「学生台账 → 导入学生 → 选择 CSV 文件」导入（学号重复自动跳过）。
- **其余数据（谈话 / 文件索引 / 画像 / 设置）**：旧版「设置 → 导出备份」得到 `辅导员工作站备份_日期.json` → 新版本「设置 → 导入备份」整体导入。
- 也可以直接拷贝整个 `db/workstation.db` 文件到新电脑（换机迁移）。

## 常见问题

- **服务启动后浏览器没自动打开？** 手动在浏览器地址栏输入 `http://127.0.0.1:8790/`。
- **端口被占用？** 启动脚本会自动改用 8791–8799 中的可用端口，并打印实际地址；跨站写请求防护按实际端口自动匹配本机页面。
- **锁屏密码忘了？** 密码哈希存在数据库中，无法找回；可在「设置 → 清空全部数据」后重新使用（会丢失数据，请务必先导出备份）。
- **安全说明**：本服务仅监听本机回环地址 `127.0.0.1`，不对外网开放，数据不会上传；学生信息属敏感个人信息，建议对项目所在磁盘启用「文件保险箱」加密。画像中家长信息默认折叠，避免投屏时泄露联系方式。

## 后端 API 一览（供参考）

- `GET  /api/state` — 全量数据（含奖助项目 / 困难认定 / 申报记录）
- `GET  /api/dbinfo` — 数据库连接信息（路径 / 大小 / 数据量）
- `GET  /api/backup/db` — 导出 db 格式备份（下载数据库文件副本）
- `POST /api/db/openfolder` — 在访达中打开数据库所在文件夹
- `POST /api/students` / `PUT|DELETE /api/students/{id}` — 学生增改删（学号唯一）
- `POST /api/talks` / `PUT|DELETE /api/talks/{id}` — 谈话增改删
- `POST /api/talks/{id}/done` — 标记跟进完成
- `POST /api/files` / `PUT|DELETE /api/files/{id}` — 文件索引增改删
- `POST /api/focus/upload` — 重点关注材料上传（multipart：sid、type、date、file，自动改名并落盘）
- `POST /api/focus/openfolder` — 在访达中打开「重点关注文件」文件夹
- `POST /api/aid/hardship` / `PUT|DELETE /api/aid/hardship/{id}` — 困难认定增改删（每生每学年自动 upsert）
- `POST /api/import/scholarships` / `POST /api/import/grants` — 批量导入奖学金 / 助学金（学号绑定台账 + 等次校验 + 同学年去重，返回 `{imported, skips}`）
- `DELETE /api/scholarships/{id}` / `DELETE /api/grants/{id}` — 删除单条奖学金 / 助学金
- `POST /api/aid/upload` — 奖助材料上传（multipart：sid、pid、type、date、file，自动改名并落盘）
- `POST /api/aid/openfolder` — 在访达中打开「奖助文件」文件夹
- `POST /api/portraits/tags` — 添加画像标签
- `PUT  /api/settings` — 保存设置（含 meta）
- `POST /api/import/students` — 批量导入学生（服务端去重，返回 `{imported, skips}`）
- `POST /api/import/hardship` — 批量导入困难认定（学号匹配 + 等级校验 + 同学年去重，返回 `{imported, skips}`）
- `POST /api/import/talks` — 批量导入谈话（学号匹配 + 必填校验，返回 `{imported, skips}`）
- `POST /api/import/concerns` — 批量导入重点关注（学号绑定台账 + 类型/级别校验 + 同类型覆盖，返回 `{imported, skips}`）
- `POST /api/backup/import` — 导入旧版备份 JSON
- `POST /api/seed` / `POST /api/reset` — 载入示例数据 / 清空

> 示例数据（6 名学生、8 条谈话、6 个文件索引）全部为虚构，仅用于体验功能。

## 高级（可选）

- 可用环境变量 `WS_DB=/路径/xxx.db` 指定数据库文件位置（默认 `db/workstation.db`），便于测试或分离数据。
- 静态页面与脚本启用了「每次重新校验缓存」，升级或修改代码后刷新浏览器即可生效。
